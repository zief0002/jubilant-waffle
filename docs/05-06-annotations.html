24  Annotations: Contextualing Interesting Findings

This chapter will focus on how we can continue to improve the information conveyed in a plot by adding annotations. Annotations are the text and guides (e.g., arrows) that explain or clarify information in a plot. They often provide additional context or information to aid readers in interpreting the data. Figure 24.1 shows a plot of the men’s marathon world record times from 1908–2014. This plot has five annotations that further explain interesting aspects of the plot by adding context about the data.

It is important to think about what aspects of the plot to annotate. Yau (2013) provides some advice on this, suggesting that some things to consider annotating are highlighted elements, outliers, clusters, explanations of trends, important contextual milestones or reference points, and interesting observations. For example, consider the five annotations in Figure 24.1:

  1. “Record dropped by almost 15 mins in the 13 months between July 1908 and August 1909 with 6 different record holders”
  2. “Jim Peters (UK) set the record then broke his own record 3 times between 1952-54”
  3. “Derek Clayton (Australia) was first man to break the 2:10 barrier in December 1967. In the following 50 years the record would only drop by a further 6:39”
  4. The last 6 record times have occurred at the Berlin Marathon”
  5. Current record holder Dennis Kimetto (Kenya) set new mark 2:02:57 at Berlin in 2014”

In addition to the text, each of the annotations also includes a short light-grey line that links the text annotation to a particular data point.

The first annotation point out an interesting finding in the data where there was a large drop in the world record time over a short period of time. The second annotation indicates a cluster of data points that have an interesting contextual story (they all belong to the same person). The third annotation indicates an important contextual milestone, namely the breaking of the 2:10 barrier. The fourth annotation explains several highlighted data points and why they are highlighted. The last annotation again points out something of interest contextually (namely who the current record holder was at the time the plot was made).


24.1 Example Plot to Annotate

We will use the world-happiness.csv data to illustrate how to add annotations to a plot. After loading libraries and importing the data, we will create a scatterplot to examine the relationship between countries’ GDP and their happiness.

########################
# Load libraries
########################

library(tidyverse)


########################
# Import data
########################

bls = read_csv("data/bls-professional-earnings.csv")


########################
# Create scatterplot
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_point(shape = 21, color = "black", fill = "#d50000", alpha = 0.7, size = 3) +
  labs(
    title = "2025 Pay by Occupation\n", 
    subtitle = "",
    caption = "\nSource: Bureau of Labor Statistics",
    x = "Men weekly median salary",
    y = "Women weekly median salary"
  ) +
  theme_classic()

What annotations might you add to this plot? We could describe the trend in the plot—it is a strong, positive, linear trend indicating that occupations in which men make a higher weekly salary are the same occupations in which women make a higher weekly salary. While this describes the trend, it doesn’t necessarily help readers understand gender pay gaps.

In a similar plot based on 2011 data Yau (2013) suggested several annotations that would help contextualize pay gaps in these occupations. Figure 24.3 shows the plot of weekly median pay for both men and women but also includes several of Yau’s annotations.

  1. A diagonal line has been added to indicate where the median weekly pay is the same for both men and women.
  2. Text annotations have been added to label the line as well as the areas in the plot where men earn more than women and where women earn more than men.
  3. The occupations where women earn more than men have been labelled to provide context.

It isn’t always clear what annotations might be useful. The best way to figure this out is to have other people give you feedback about how they are interpreting your plot, what they find interesting, and what they don’t understand. As Yau pointed out:

In the end, you must consider what your audience will or might not understand graphically and statistically, and annotate based on that (Yau, 2013, p. 233).

We will add each of Yau’s annotations in turn.


24.2 Adding the Diagonal Line

The first annotation we will add is the line indicating equal pay for men and women. This line has the equation:

\[ y = x \]

If we write this in slope-intercept form1, the equation is:

\[ y = 0 + 1x \]

To add a specific line for which we know the slope-intercept form to our plot, we use the geom_abline() layer. This function takes two arguments: intercept= and slope=. We provide those arguments the value of the intercept and slope, respectively.

########################
# Create scatterplot
# Add diagonal line
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_point(shape = 21, color = "black", fill = "#d50000", alpha = 0.7, size = 3) +
  geom_abline(intercept = 0, slope = 1) +
  labs(
    title = "2025 Pay by Occupation\n", 
    subtitle = "",
    caption = "\nSource: Bureau of Labor Statistics",
    x = "Men weekly median salary",
    y = "Women weekly median salary"
  ) +
  theme_classic()


24.3 Adding a Text Annotation to the Plot

Now that we have added a line, we can also add a label for the line to help readers quickly parse its meaning. To add text annotations, we include annotate() layers to our plot code, one layer for each annotation. The syntax for this layer when adding a text annotation looks like the following:

annotate("text", x = , y = , label = "")

The string "text" indicates that the annotation is text. The arguments x= and y= give the x- and y-coordinates where you want the text annotation to appear in the plot. Finally, the label= argument includes the text that you want to appear in the annotation.

For example, let’s add the text annotation of “Equal Pay” at the coordinate (3000, 3000). Note that picking the coordinates for your annotation is a bit of trial-and-error. Pick a coordinate that seems reasonable to start, and then change it until you get it to look good.

########################
# Create scatterplot
# Add diagonal line
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_point(shape = 21, color = "black", fill = "#d50000", alpha = 0.7, size = 3) +
  geom_abline(intercept = 0, slope = 1) +
  annotate("text", x = 3000, y = 3000, label = "Equal Pay") +
  labs(
    title = "2025 Pay by Occupation\n", 
    subtitle = "",
    caption = "\nSource: Bureau of Labor Statistics",
    x = "Men weekly median salary",
    y = "Women weekly median salary"
  ) +
  theme_classic()

Notice that the text annotation is centered at the coordinate we specified, namely (3000, 3000). It might be nice to have the text be at the same orientation as our diagonal line. To do this we need to change the angle of orientation for the text annotation by using angle=. The line is roughly at 45 degrees (if the aspect ratio of your plot is a square). Depending on the aspect ratio of your plot you will need to adjust the angle via trial-and-error. (Note that as you shift the angle, you may also need to adjust the x- and y-coordinates for the text to make it look good!)

########################
# Create scatterplot
# Add diagonal line
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_point(shape = 21, color = "black", fill = "#d50000", alpha = 0.7, size = 3) +
  geom_abline(intercept = 0, slope = 1) +
  annotate("text", x = 2700, y = 2850, label = "Equal Pay", angle = 41) +
  labs(
    title = "2025 Pay by Occupation\n", 
    subtitle = "",
    caption = "\nSource: Bureau of Labor Statistics",
    x = "Men weekly median salary",
    y = "Women weekly median salary"
  ) +
  theme_classic()

We can also add the text annotations “WOMEN PAID MORE” and “MEN PAID MORE” in the same manner, by adding two more annotate() layers. Instead of centering the text at the x- and y-coordinates enteredi nthe layer, we will left-justify the text at the coordinate. To do that, we can include the argument hjust=0. This sets the horizontal justification—this takes a value between 0 and 1 where left justified is 0, right justified is 1, centered (the default) is 0.5.

########################
# Create scatterplot
# Add diagonal line
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_point(shape = 21, color = "black", fill = "#d50000", alpha = 0.7, size = 3) +
  geom_abline(intercept = 0, slope = 1) +
  annotate("text", x = 2700, y = 2850, label = "Equal Pay", angle = 41) +
  annotate("text", x = 300, y = 3150, label = "WOMEN PAID MORE", hjust = 0) +
  annotate("text", x = 3133, y = 400, label = "MEN PAID MORE", hjust = 1) +
  labs(
    title = "2025 Pay by Occupation\n", 
    subtitle = "",
    caption = "\nSource: Bureau of Labor Statistics",
    x = "Men weekly median salary",
    y = "Women weekly median salary"
  ) +
  theme_classic()


24.4 Adding Labels to Observations

We now want to identify the three occupations that are above the line; those occupations in which women have a higher median salary than men. There are two ways we can do this: (1) using the data viewer to scan each occupation to determine which ones have a higher median pay for women than for men; or (2) using code. To use code, we will use the filter() function. This function takes the name of the data object and a logical statement (something that evaluates as TRUE or FALSE). In our example:

# Determine which occupations have a higher median pay
# for women than men
filter(bls, med_weeklypay_women > med_weeklypay_men)
# A tibble: 3 × 4
  Occupation             med_weeklypay_men med_weeklypay_women occupation_subcat
  <chr>                              <dbl>               <dbl> <chr>            
1 Educational, guidance…              1160                1396 Community and so…
2 Counselors, all other               1073                1155 Community and so…
3 Producers and directo…              1773                1802 Arts, design, en…

Aside from identifying the occupations, we also get the weekly pay values which will help us determine where to put the text. We will offset the text annotations for these occupations so that the text doesn’t sit on top of the points. Again, we will include three new annotate() layers to do this. In these annotations, instead of using “text”, we will use “label”, which adds a border around the text annotation.

########################
# Create scatterplot
# Add labels
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_point(shape = 21, color = "black", fill = "#d50000", alpha = 0.7, size = 3) +
  geom_abline(intercept = 0, slope = 1) +
  annotate("text", x = 2700, y = 2850, label = "Equal Pay", angle = 41) +
  annotate("text", x = 300, y = 3150, label = "WOMEN PAID MORE", hjust = 0) +
  annotate("text", x = 3133, y = 400, label = "MEN PAID MORE", hjust = 1) +
  annotate("label", x = 1000, y = 1900, label = "Counselor\n(Education)", size = 3) +
  annotate("label", x = 600, y = 1300, label = "Counselor\n(Other)", size = 3) +
  annotate("label", x = 1550, y = 2400, label = "Producers/\nDirectors ", size = 3) +
  labs(
    title = "2025 Pay by Occupation\n", 
    subtitle = "",
    caption = "\nSource: Bureau of Labor Statistics",
    x = "Men weekly median salary",
    y = "Women weekly median salary"
  ) +
  theme_classic()


24.5 Adding Line Segments to Connect Labels to Points

The next thing we will do is add a pointer from the annotated text label to the point in the scatterplot that corresponds to the respective occupation. To do this we will add an annotation that is a line segment rather than text. The syntax for this is as follows:

annotate("segment", x = , y = , xend = , yend =)

The line segment extends from the coordinate (x, y) to the coordinate (xend, yend). Since we need three line segments, we need three of these annotation layers. Again, the coordinates you will need are a bit of trial-and-error, adapting them until the pointer looks good.

########################
# Create scatterplot
# Add labels and connectors
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_point(shape = 21, color = "black", fill = "#d50000", alpha = 0.7, size = 3) +
  geom_abline(intercept = 0, slope = 1) +
  annotate("text", x = 2700, y = 2850, label = "Equal Pay", angle = 41) +
  annotate("text", x = 300, y = 3150, label = "WOMEN PAID MORE", hjust = 0) +
  annotate("text", x = 3133, y = 400, label = "MEN PAID MORE", hjust = 1) +
  # Occupation Labels
  annotate("label", x = 1000, y = 1900, label = "Counselor\n(Education)", size = 3) +
  annotate("label", x = 600, y = 1300, label = "Counselor\n(Other)", size = 3) +
  annotate("label", x = 1550, y = 2400, label = "Producers/\nDirectors ", size = 3) +
  # Segments connecting labels and points
  annotate("segment", x = 1000, y = 1900, xend = 1150, yend = 1440, linewidth = 0.2) + # Education Counselors
  annotate("segment", x = 600, y = 1300, xend = 1033, yend = 1175, linewidth = 0.2) + # Other Counselors
  annotate("segment", x = 1550, y = 2400, xend = 1753, yend = 1852, linewidth = 0.2) + # Producers
  labs(
    title = "2025 Pay by Occupation\n", 
    subtitle = "",
    caption = "\nSource: Bureau of Labor Statistics",
    x = "Men weekly median salary",
    y = "Women weekly median salary"
  ) +
  theme_classic()

Since the segment annotations came later in the code, they were drawn on top of the labels. We will change the order of the code to have the segments before the observation labels. This will place the label on top of the segments making the plot look better.

########################
# Create scatterplot
# Add labels and connectors
# Place labels on top of connectors
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_point(shape = 21, color = "black", fill = "#d50000", alpha = 0.7, size = 3) +
  geom_abline(intercept = 0, slope = 1) +
  annotate("text", x = 2700, y = 2850, label = "Equal Pay", angle = 41) +
  annotate("text", x = 300, y = 3150, label = "WOMEN PAID MORE", hjust = 0) +
  annotate("text", x = 3133, y = 400, label = "MEN PAID MORE", hjust = 1) +
  # Segments connecting labels and points
  annotate("segment", x = 1000, y = 1900, xend = 1150, yend = 1440, linewidth = 0.2) + # Education Counselors
  annotate("segment", x = 600, y = 1300, xend = 1033, yend = 1175, linewidth = 0.2) + # Other Counselors
  annotate("segment", x = 1550, y = 2400, xend = 1753, yend = 1852, linewidth = 0.2) + # Producers
  # Occupation Labels
  annotate("label", x = 1000, y = 1900, label = "Counselor\n(Education)", size = 3) +
  annotate("label", x = 600, y = 1300, label = "Counselor\n(Other)", size = 3) +
  annotate("label", x = 1550, y = 2400, label = "Producers/\nDirectors ", size = 3) +

    title = "2025 Pay by Occupation\n",

FYI

When you change the size of text, you may need to re-modify coordinates to make it look good again! Similarly, if you change the aspect ratio of your plot, you will also likely need to change them.


24.6 Labeling All of the Points

There are times that you want to add a label to identify all of the points in your scatterplot. To do this we will replace the geom_point() layer with a geom_text() layer. We supply this layer with an aes() function that includes the argument label=. We then give that argument the attribute name that includes the text labels for each observation. For example, the Occupation attribute includes labels for each occupation in the data. The syntax to label each point with its occupation name is:

########################
# Create scatterplot
# Add labels for all observations
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_text(aes(label = Occupation), size = 3) +
  labs(
    title = "2025 Pay by Occupation\n", 
    subtitle = "",
    caption = "\nSource: Bureau of Labor Statistics",
    x = "Men weekly median salary",
    y = "Women weekly median salary"
  ) +
  theme_classic()

Remember that text writes the label without a border and label adds a box around the text. If you prefer to have a box around the text, use geom_label() rather than geom_text()—the arguments are identical in these two functions.

########################
# Create scatterplot
# Add labels with boxes for all observations
########################

ggplot(data = bls, aes(x = med_weeklypay_men, y = med_weeklypay_women)) +
  geom_label(aes(label = Occupation), size = 3) +
  labs(
    title = "2025 Pay by Occupation\n", 
    subtitle = "",
    caption = "\nSource: Bureau of Labor Statistics",
    x = "Men weekly median salary",
    y = "Women weekly median salary"
  ) +
  theme_classic()

While the text can be useful to identify the different observations in a plot, it also can make a plot difficult to read since the text often overlaps other text. In our plot, many of the occupations are difficult to read and in places the text runs off the screen. Because of this, adding labels to all the observations is most useful when the datasets are smaller. With datasets that have many observations, it is often better to use points, and then call attention to interesting observations using annotate().
